* Local runtime packages used GEOIP.dat extracted from the user-supplied APK (SHA256 6701aa3d9a9ea6c5e2026c8e73f199a9d6abe06257d9364e2bbf0874d5ccaa3f); its separate upstream data provenance has not been established. This dataset is excluded from the public source repository. See resources/README.md for optional compatible data inputs.

Runtime packages include the desktop source under source/. Analysis evidence and decompiled output remain in the local workspace and are excluded from the public repository and runtime packages. No original app credentials or license signing material are bundled. Compiled runtimes and drivers are excluded from Git; their recorded identities and applicable licenses remain available.

The shipped custom core restores standalone listener/TUN initialization and adds enforcement of OpenVPN verify-x509-name (name/name-prefix) through scripts/custom-core-desktop.patch. The patch retains CA chain and server-authentication checks before matching the leaf certificate common name. This patch is distributed with the application source; its SHA256 is recorded in core/build.json. The unmodified upstream source archive and the patch together describe the corresponding core source.

The official tunnel helper intentionally does not authenticate its outer TLS certificate. The app relies on the inner OpenVPN certificate verification for server authentication and preserves that profile's CA/name constraints. AzadNet is not an official Windscribe client; no Windscribe account credentials, configurations or subscription rights are bundled.

The shipped tunnel executable applies scripts/windscribe-tunnel.patch to the pinned upstream source. This original compatibility patch supplies initial hybrid TLS 1.3 key shares whenever those groups are advertised by randomized uTLS ClientHello variants; uTLS 1.8.2 cannot handle a HelloRetryRequest selecting such an initially omitted hybrid share. The patch and a 2,000-spec regression test are included in source/scripts/. The platform manifest records its SHA256 and test result. The source archive remains the unmodified upstream commit.

Licenses/notices for the tunnel's pinned Go module dependencies, including uTLS and the modified WebSocket dependency, are included under licenses/Windscribe-Tunnel-dependencies/ in runtime packages and resources/licenses/Windscribe-Tunnel-dependencies/ in this repository. index.json records module identities and the copied license filenames. The build regenerates this inventory from the verified source modules.

The Windscribe account integration is original JavaScript interoperability code based on public protocol interfaces from Windscribe/wsnet commit 544a5365cf5123a73b344c69e7a393c81c8fb622 and Windscribe/browser-extension commit ed83749ad1a4163f24e39572fc9597a4091a0ee7. It does not bundle those SDKs. The publicly published signature/client-authentication salts are protocol constants; no user's password, session token or private developer key is distributed. Session persistence uses the Electron runtime's operating-system safeStorage API; Linux plaintext fallback is not used.
